# Política de seguridad — ATLAS-PTY

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este repositorio, repórtala de forma privada y responsable:

- Escríbele a atencionAI@outlook.com con la descripción y los pasos para reproducirla.
- No explotes la vulnerabilidad más allá de lo necesario para demostrarla.
- No incluyas datos sensibles en el reporte.
- No publiques el hallazgo hasta que se confirme la corrección.

## Divulgación responsable

Se sigue la divulgación responsable: el hallazgo se reporta en privado, se corrige y solo después se puede publicar, con el permiso del responsable.

## Alcance

- Solo se reportan vulnerabilidades de este repositorio.
- No se prueban sistemas de terceros sin autorización escrita.
- No se guardan credenciales, secretos ni tokens en este repositorio.
